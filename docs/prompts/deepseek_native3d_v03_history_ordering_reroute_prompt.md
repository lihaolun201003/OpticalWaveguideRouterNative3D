## 1. 本轮要解决的真实瓶颈

v0.2 已核实：

- crosswall 2/4/8/16 全部合法提交；16 条路径是在不同 y 泳道做同一三维翻墙。
- stress_swap_04：搜到4条候选，但全部自间距违规，合法提交0。
- stress_swap_08：搜到6条候选，合法提交5；另外有自间距违规、有限图耗尽、端口附着失败。
- stress4 的 occupancy revision 始终为0，尚无已发布网阻挡。因此只换顺序或 rip-up 不能解决它的首要问题。
- 当前搜索只按规范 node ID 保留最低 g，没有路径历史；它找到一条会接近自身的路径后，被后验拒绝，没有继续寻找合法替代路径。

实现顺序固定为：

```text
搜索侧自间距与路径历史
    → 4/8通道压力恢复
    → 确定性net ordering
    → 有预算的局部rip-up & reroute
    → 16通道扰动/置换基准
```

不要先堆调度策略来掩盖单网自身违规。不要仅修改验收器使旧候选通过。

## 2. 第一阶段：让自间距进入搜索

### 2.1 保留真实路径历史的标签

实现 history-aware search label，至少包含：

```text
canonical_node_id
parent_label_id
真实前缀曲线或其不可变引用
累计弧长
g / h / f
有序边历史或完整几何历史的身份
```

- 同一规范 pose、不同历史，未来可行性可能不同，必须保留多个 label。
- 不能继续用 nodeID 的单个 best_g 支配所有历史。
- visited-node 集合相同、路径长度相近、最后几段相同，都不能未经证明就视为历史等价。
- 第一版可以不做跨历史 dominance，不先追求大规模剪枝。
- 可以归并确实表示同一 `P(s)` 的历史，例如连续共线同向直线的不同分段；给出等价依据并验证成本和政策不变。
- 若使用哈希，碰撞不能造成无证明的历史合并。

建议独立新增 `search/history_astar.py` 或等价入口，复用现有静态边生成与几何验收，不大改旧 A* 使基线不可复跑。

### 2.2 新边入 OPEN 前的增量检查

当前局部豁免政策保持：

```text
|s-t| >= ell_local
ell_local = 2*dmin
```

沿用 v0.2 的单位和公开几何政策，不调整 dmin/ell_local 来挽救压力案例。

对每个 label 扩展出的真实新边：

1. 检查新边自身内部的自间距，包括多段端口/目标连接器。
2. 检查所有前缀曲线与新边的非局部接近，正确带入全局弧长 offset。
3. 检查连接位置与切向一致性。
4. 已认证前缀可按归纳复用，不必每次重做所有前缀-前缀组合。

要求：

- violation 不入 OPEN。
- undecided 不当安全；记录数值拒绝与细化上限。
- 同段、相邻段远处和非相邻段都遵守相同全局弧长语义。
- 多段终端连接器不能绕过历史检查。
- 静态边缓存只缓存相对于固定场景/占用的合法性；历史相关可行性必须随 label 检查。
- 冲突属于“历史+边”，不能根据一个 witness 全局禁掉该边。

所有候选仍从真正三维动作产生，不调用二维 Router 或抬升修补。

### 2.3 搜索预算与保证范围

cost 继续采用真实长度，ZeroCongestion；heuristic 保持可采纳的三维距离下界。

- 保持正确 A* 终止。
- 记录展开 label 数、每 node label 数、峰值活跃 label、历史检查次数及耗时。
- 明确时间、扩展、label、候选、步数等限制；触及限制是 budget/limit 状态，不是无解证明。
- 如果使用 beam、每 node label cap、K-best 等限制，明确标为近似模式；不能宣称完备。
- 不声称连续空间全局最优，也不直接继承旧 pose 图的最优性声明。
- 不回退到不考虑历史的 Router 后把其结果写成 v0.3 的成功。

若完整 label 搜索过重，可以实现有预算的 K-best 完整候选搜索作为明确替代：真正保留不同完整边历史，逐个验收并继续找下一条；K封顶失败不是 search_exhausted。报告其保证范围，不能只重复得到同一条被拒路径。

### 2.4 必须验证的历史反例

- 两条前缀到达同一规范 pose：便宜前缀挡住未来，昂贵前缀能够合法到目标。新搜索必须保留可行前缀。
- 对一个微型有限历史图，用独立 Dijkstra/穷举作对照，不能仅把同一 A* 的 h 设为0。
- 新边内部自交、前缀×新边交叉、相邻段远处回返均在扩展时拒绝。
- 同一曲线重分段不改变判定。
- 终端连接器导致自接近时，继续搜索其他 label/连接器，而不是立刻结束。
- 至少一个具有独立验证合法替代路线的真实三维场景：v0.2候选被后验拒绝，v0.3找到并提交合法替代路径。

已知合法路径可以作为测试 oracle，但不能作为 Router 的 waypoint、预制路径或层高提示。

## 3. 压力恢复与端口候选覆盖

先保持输入顺序，重跑原 stress_swap_04/08，不修改它们的 chip、障碍、端口或硬约束。

先逐网做“没有其他网占用”的控制运行，区分：

- 单网自身历史问题。
- 端口候选集合不足。
- 已发布网确实阻挡。
- 预算停止。

当前端口生成可能达到少量边阈值就提前停止。接入历史检查后，最早生成的边可能全部自身非法；不能据此认定所有接入都不存在。

必要时按通用、有限、可配置规则继续枚举端口候选或并行连接器族：

- 保留同端点但不同实际曲线的替代边。
- 自身不合法的连接器不要占满有效候选额度。
- 披露候选节点/边上限与图参数变更，做消融。
- 不为某个案例指定中点、最高 z 或端口专用路线。
- 不通过放宽 Rmin、spacing、边界、端口切向或自间距政策获取成功。

原 stress4/8 的连续空间或当前有限动作图全可行性尚未证明，不盲目要求全部成功，也不能把失败都归因于拥塞。
必须以受控、有独立合法解的案例证明新搜索确实能恢复路径；原压力数据如实比较并解释剩余失败。

## 4. 第二阶段：确定性 net ordering

history-aware 单网工作后，保留输入顺序基线，再实现少量固定策略，例如：

- input_order。
- 欧氏长度下界较长优先。
- 通用端口可行候选较少优先。

平局稳定按 net_id 处理。记录用于排序的数值、计算开销、最终顺序和配置，禁止为已知案例硬编码顺序。

统一比较：

1. 合法已提交网数。
2. 同等完成条件下的合法已提交路径总长度。
3. 时间、扩展和内存。

失败候选长度、所有尝试累计长度、已提交路径长度分别统计。v0.2 的部分“总长度”包含失败候选，不能直接拿来优化调度质量。

## 5. 第三阶段：有预算的局部 rip-up & reroute

只实现小窗口、有限轮数，不做全局复杂优化。

建议初始配置：

```text
窗口最多：失败网 + 1或2条已提交阻塞网
重布轮数：最多3轮
固定、有限的窗口顺序尝试
每网原有搜索预算 + 明确的整案例预算
```

阻塞网应有可追踪 net_id，来自实际占用或候选与占用的几何关系。可采用简单确定性选择，不要求复杂冲突图。

规则：

- 自间距失败先由单网历史搜索处理，不能靠拆其他网解释。
- 静态障碍/静态参考线不能 rip-up。
- 每次占用变化后新建图；继续隔离 warm/prebuilt 分支。
- 使用事务：保存当前合法快照，在临时占用中移除窗口网，按候选顺序重布。
- 新路径仍通过单网、历史、自间距和网间距验收。
- 最终提交集合独立联合验收通过，且原先完成的网不丢失，才替换发布。
- 失败或不能认证时完整回滚；未影响网的曲线内容保持不变。
- 原 Occupancy 的不可变发布契约不能悄悄破坏。通过显式批量替换/事务/新 revision 表示重布，保留旧版本和事件记录。
- 记录尝试窗口、顺序、被移除/重布的 net、占用 revision、成功/回滚原因。

至少一个受控案例证明：固定顺序失败，有限局部重布恢复合法完成。不能仅有“代码包含 reroute”而没有实际触发。

## 7. 独立验收与证据口径

继续使用独立 JSON joint validator，重做最终提交集合的端口、C1、Rmin、边界、障碍、静态占用、自间距和网间距。

分别输出：

```text
accepted_set_valid
all_requested_nets_committed
routed_count / verified_count / committed_count
unique_nets_with_candidate
attempt_count / reroute_count / rollback_count
total_committed_length_um
total_candidate_length_um
```

joint verdict=pass 只证明验收/拒绝证据一致及提交集合合法，不等于全部请求网成功。

对距离数字准确命名：密集采样或数值极小化得到的“找到的最小值”通常是上界估计，不写成精确真值。
例如 R=50 的圆弧上弧长差10 μm的两个点，距离为 `100*sin(0.1)=9.983341664683 μm`，符合 ell_local=10 的检查域。因此 v0.2采样得到的10.914139 μm不能称全域精确最小值；这不推翻已认证下界≥5的合法性。
报告继续把认证下界、达到的上界/witness、采样估计分开。
